Ionogram — Time-of-Flight Cluster Analysis

GPS-referenced propagation delay: detection time minus scheduled broadcast time. Clusters correspond to ionospheric propagation modes (1F2, 2F2, 1E, etc.).
Interpretation guide (after Griffiths 2026): Rank-0 arrivals (dominant path) cluster near the model-predicted ToF. Rank-1+ arrivals (secondary paths) appear at longer delays — each cluster corresponds to a distinct propagation mode (1F, 2F, sporadic-E, sidescatter). The delay difference between rank-0 and rank-1 directly encodes the F2 virtual height. SNR separates modes: higher-hop paths are weaker due to additional D-layer transits.
