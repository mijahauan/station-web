dTEC — phase-rate dTEC (assumes no layer-height motion)

Carrier-phase rate of each path this station hears, converted to a TEC rate. One series per frequency: a frequency several stations share arrives as one composite carrier. Signatures that line up across distinct frequencies may mark travelling ionospheric disturbances (TIDs).
What the rate measures: A single-frequency carrier phase changes when the TEC along the path changes and when the reflecting layer moves up or down. This page converts the whole phase rate to a TEC rate, which assumes the layer height holds still. Read it as phase-rate dTEC, not as a TEC measurement.

Noise floor: computed from this window's data (see the tile below), in the chart's unit, TECU/s. Signatures across the WWV, WWVH and BPM paths can constrain a disturbance's direction and speed when they appear on distinct frequencies.
